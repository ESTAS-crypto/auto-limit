# Paket Quota Radar

Isi paket ini:

- `index.html`: galeri mockup. Dobel-klik untuk membuka di browser. Pilih halaman di sebelah kiri, atau pakai tombol panah atas dan bawah.
- `PROMPT-untuk-agent.md`: prompt lengkap untuk Antigravity atau agent coding lain. Lampirkan screenshot dari galeri saat memberikannya ke agent.
- `pages/`: 10 halaman desktop dan 6 halaman HP sebagai HTML biasa. Animasi dan interaksinya (saklar, tombol mode, filter, angka menghitung naik, efek tombol berhasil) memakai CSS murni, jadi bisa dipelajari langsung.
- `css/`: stylesheet bersama (`quota.css` dan `quota2.css`).
- `assets/`: 12 ikon custom (`icons/*.svg`), tiga suasana maskot Blip, dan logo.

Catatan:

- Font (Bricolage Grotesque, Inter, JetBrains Mono) dimuat dari Google Fonts, jadi butuh internet. Tanpa internet tampil font cadangan sistem.
- Semua angka dan email di mockup adalah data contoh.
- Tombol dan menu navigasi belum berpindah halaman. Setiap halaman berdiri sendiri.
- Ikon di CSS dibuat sebagai masker, jadi warnanya mengikuti `color` elemen.
